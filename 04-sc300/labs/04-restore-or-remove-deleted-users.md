# Exercise: Restore or Remove Deleted Users

**Bron:** SC-300 Learning Path; Implement an identity management solution using Microsoft Entra ID

## Doel
Een user verwijderen en herstellen binnen Entra ID, om te oefenen met de restore/remove workflow.

## Stappen

### Verwijderen
1. Microsoft Entra admin center -> Identity -> Users
2. Checkbox aanvinken bij de te verwijderen user
3. Delete user -> bevestigen met OK

### Herstellen
1. Users -> Deleted users
2. Betreffende user selecteren
3. Restore user -> bevestigen met OK
4. Controleren in All users dat de user is teruggekomen

## Resultaat
Uitgevoerd in de sandbox. User is weer teruggekomen

## Wat dit aantoont
- Begrip van de restore/remove workflow in Entra ID
- Kennis van de 30-dagen suspended state voordat een verwijderde user permanent wordt verwijderd
- Bewustzijn dat permanente verwijdering (na 30 dagen of expliciet) niet terug te draaien is
