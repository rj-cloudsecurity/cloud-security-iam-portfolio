# Exercise: Setting Tenant-Wide Properties

**Bron:** SC-300 Learning Path; Implement an identity management solution using Microsoft Entra ID

## Doel
Tenant-wide properties verkennen: display name, Country/Region, Location, en Tenant ID.

## Stappen
1. Tenant display name gewijzigd: Microsoft Entra ID -> Manage -> Properties -> Name -> Save
2. Country/Region gecontroleerd: Properties -> Tenant properties (niet aanpasbaar na tenant-creatie)
3. Location gecontroleerd: Properties -> Tenant properties
4. Tenant ID opgezocht: Properties -> Tenant properties

## Resultaat
- Tenant display name aangepast
- Country/Region, Location en Tenant ID van de tenant vastgesteld

## Wat dit aantoont
- Praktische ervaring met het beheren van tenant-wide properties in Entra ID
- Begrip van welke tenant-instellingen wel/niet wijzigbaar zijn na aanmaken (bv. Country/Region is permanent)
