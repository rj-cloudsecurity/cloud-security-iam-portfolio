# Exercise: Add Groups in Microsoft Entra ID

**Bron:** SC-300 Learning Path; Implement an identity management solution using Microsoft Entra ID

## Doel
Een Microsoft 365 group aanmaken binnen Entra ID, om te oefenen met group creation.

## Stappen
1. Microsoft Entra admin center -> Identity -> Groups -> New group
2. Group type: Microsoft 365
3. Group name: Northwest Sales
4. Membership type: Assigned
5. Owner: eigen administrator account
6. Member: 1 member toevoegen
7. Verifiëren in All groups (soms een paar keer refreshen nodig)

## Resultaat
Uitgevoerd in de sandbox; zie sandbox-entry voor details.

## Wat dit aantoont
- Praktische ervaring met het aanmaken van een Microsoft 365 group
- Begrip van het verschil tussen Security groups en Microsoft 365 groups
