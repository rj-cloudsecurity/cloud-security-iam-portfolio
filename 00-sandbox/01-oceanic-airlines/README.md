# Sandbox Context: Oceanic Airlines

**Type:** Fictional organisation for a sandbox tenant

## Background
Oceanic Airlines is a fictional company that I use as the context for all sandbox experiments in my personal test tenant. The name and logo ("Oceanic Airlines") are taken from the TV series Lost. The company has no relation to any real company.

## How the sandbox came about
I am preparing for the Microsoft SC-300 (Identity and Access Administrator). Theory and practice exams alone turned out not to be enough: when I got an answer wrong, I knew which feature it was, but not where you configure it or how it behaves. So I set up my own test tenant, and I work through the Microsoft Learn material and the questions from practice exams as hands-on exercises in the portal.

It works like this: I take a Learn module, a practice exam question or a topic I had not worked with yet, carry out the scenario in the tenant, note the portal path in the [Hands-on Review](/04-sc300/exam-prep/sc300-hands-on-review.md) where it comes from a practice exam, and record the exercise as a numbered entry in this folder. Each entry describes what I did, what happened and what that shows, including when something failed or could not be confirmed.

## Setup of the tenant
- One tenant named Oceanic Airlines; I deliberately do not work with multiple tenants, so exercises that need a second tenant are treated as theory
- Users, groups and departments are named after characters and things from Lost (for example the groups DharmaInitiative and Island Resources and the administrative unit The Looking Glass)
- For licence-bound features I use a Microsoft Entra Suite trial

## Limitations
A personal tenant with a Microsoft Entra Suite trial has limitations. Where an exercise cannot be fully done because of that, the entry says so and the [Hands-on Review](/04-sc300/exam-prep/sc300-hands-on-review.md) marks it as Skipped, instead of me assuming the result.

## Purpose
A consistent, recognisable fictional context for sandbox experiments, and evidence of what I have done myself in the portal, alongside the theory for the SC-300.
