# Sandbox: Creating an Attribute Set and Attribute

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Eigen verkenning, onderdeel van de SC-300 voorbereiding. Opgezet aan de hand van oefenexamenvragen die ik omzet in praktische sandbox-oefeningen.

## Aanleiding
Praktisch ervaren hoe custom security attributes zijn opgebouwd uit een attribute set en attributes.

## Doel
Een attribute set en een attribute aanmaken waarmee ik vastleg op welke manier iemand op het eiland aankwam.

## Stappen
1. Entra admin center -> Entra ID -> Custom security attributes -> **Add attribute set**: **Jacob**
2. Open de set -> **Add attribute**: **ArrivalMethod**, data type String, met vooraf gedefinieerde waarden (Flight, Freighter, Boat, Submarine, Raft)

## Resultaat
- Attribute set "Jacob" met daarin het attribute "ArrivalMethod"

## Wat dit aantoont
- Praktisch begrip van het verschil tussen een attribute set (de map) en een attribute (de eigenschap met waarden)
- Attribute sets zijn permanent: je kunt ze niet hernoemen of verwijderen
