# Sandbox: Adding First User

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Deze stap is geïnspireerd op de Microsoft Learn oefening **"Manage user roles"**, onderdeel van de SC-300 Learning Path *Implement an identity management solution using Microsoft Entra ID*. De oefening is niet letterlijk overgenomen; ik heb de Learn-voorbeelddata (user "AdeleV") vervangen door mijn eigen Oceanic Airlines-context.

## Aanleiding
Eerste gebruiker aanmaken in de Oceanic Airlines tenant, als basis om later met role assignment, groepen en governance te oefenen.

## Doel
Een gebruiker aanmaken in Entra ID.

## Stappen
1. Entra admin center -> Identity -> Users -> All Users -> **+ New User**
2. Gebruiker aangemaakt: Jack Shephard
3. **Create**

## Resultaat
- Eerste user succesvol aangemaakt in de Oceanic Airlines tenant

## Wat dit aantoont
- Praktische ervaring met user provisioning in Entra ID
- Eigen initiatief om Learn-theorie te vertalen naar een herkenbare, zelfgekozen context in plaats van de voorbeelddata één-op-één over te nemen
