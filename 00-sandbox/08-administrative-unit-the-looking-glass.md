Sandbox: Creating an Administrative Unit
Type: Eigen verkenning in persoonlijke test-tenant

Bron
Eigen verkenning, onderdeel van de SC-300 Learning Path Implement an identity management solution using Microsoft Entra ID.

Aanleiding
Praktisch ervaren hoe een administrative unit werkt.

Doel
Een administrative unit aanmaken, er users aan toevoegen en onderzoeken hoe beheer ervan gedelegeerd kan worden.

Stappen

1. Identity -> Users -> New user -> Create new user
2. Twee users aangemaakt: Bonnie en Greta
3. Identity -> Roles & admins -> Administrative units -> Add
4. Administrative unit aangemaakt: The Looking Glass
5. Bonnie en Greta toegevoegd als members van de administrative unit

Resultaat

* Administrative unit "The Looking Glass" aangemaakt met Bonnie en Greta als members
* Members van een administrative unit krijgen hierdoor zelf geen extra rechten; de AU is alleen een container

Wat dit aantoont

* Praktisch begrip van een administrative unit (gedelegeerd beheer)
* Bevestiging van eerder geleerde theorie: een rol met een AU als scope geeft een beheerder alleen rechten over de objecten in die AU
