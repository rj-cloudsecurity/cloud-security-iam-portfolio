# Sandbox: Activating Global Secure Access

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Eigen verkenning, onderdeel van de SC-300 voorbereiding. Opgezet aan de hand van oefenexamenvragen die ik omzet in praktische sandbox-oefeningen.

## Aanleiding
Voor web content filtering moet Global Secure Access eerst in de tenant actief zijn.

## Doel
Global Secure Access activeren in de sandbox-tenant.

## Stappen
1. Entra admin center -> **Global Secure Access** -> **Dashboard**
2. **Activate** gekozen
3. Gewacht tot de status op actief stond

## Resultaat
- Global Secure Access is actief in de tenant
- De onderdelen onder **Secure**, zoals Web content filtering policies en Security profiles, zijn beschikbaar

## Wat dit aantoont
- Global Secure Access moet eerst geactiveerd worden voordat je policies kunt maken
- Voor Internet Access is een licentie nodig; die zit in de Microsoft Entra Suite-trial
