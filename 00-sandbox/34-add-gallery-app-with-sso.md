# Sandbox: Adding a Gallery App with Single Sign-On

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Eigen verkenning, onderdeel van de SC-300 voorbereiding. Opgezet aan de hand van oefenexamenvragen die ik omzet in praktische sandbox-oefeningen.

## Aanleiding
Praktisch ervaren hoe je een app uit de Entra Application Gallery toevoegt en single sign-on instelt.

## Doel
Een gallery app toevoegen en een SSO-methode kiezen.

## Stappen
1. Entra admin center -> Entra ID -> **Enterprise apps** -> New application
2. In de Entra Application Gallery de app **Box** gekozen, naam **Box**, Create
3. Box -> **Single sign-on** -> **Password-based** gekozen

## Resultaat
- Gallery app Box toegevoegd als enterprise application
- SSO-methode Password-based gekozen

## Wat dit aantoont
- Een gallery app voeg je toe als enterprise application, en niet als app registration
- Voor SSO kies je een methode, zoals SAML of Password-based
