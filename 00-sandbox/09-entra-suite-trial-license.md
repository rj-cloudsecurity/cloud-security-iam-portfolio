# Sandbox: Activating a Microsoft Entra Suite Trial

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Eigen verkenning, onderdeel van de SC-300 Learning Path *Implement an identity management solution using Microsoft Entra ID*.

## Aanleiding
Voor hands-on oefeningen met functies die een betaalde licentie vereisen (zoals Identity Protection en Identity Governance) heb ik een licentie in de sandbox-tenant nodig.

## Doel
Een trial van Microsoft Entra Suite activeren en de licentie toewijzen aan mijn eigen user.

## Stappen
1. Trial van **Microsoft Entra Suite** geactiveerd in de tenant
2. Microsoft 365 admin center -> Users -> Active users -> [eigen user]
3. Licenses and apps -> **Microsoft Entra Suite** aangevinkt
4. Wijzigingen opgeslagen

## Resultaat
- Trial van Microsoft Entra Suite actief in de tenant
- Licentie toegewezen aan mijn eigen user

## Wat dit aantoont
- Praktisch begrip dat een licentie eerst in de tenant beschikbaar moet zijn en daarna per user moet worden toegewezen
- Voorbereiding op de vervolgoefeningen die een betaalde licentie nodig hebben
