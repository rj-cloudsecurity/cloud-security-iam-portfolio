# Sandbox: Creating a Microsoft 365 Group

**Type:** Eigen verkenning in persoonlijke test-tenant

## Bron
Geïnspireerd op de Microsoft Learn oefening **"Exercise - add groups in Microsoft Entra ID"**, onderdeel van de SC-300 Learning Path *Implement an identity management solution using Microsoft Entra ID*. Niet letterlijk gevolgd — eigen groupnaam gebruikt.

## Doel
Een Microsoft 365 group aanmaken, om te oefenen met group creation en het verschil met Security groups.

## Stappen
1. Identity -> Groups -> New group
2. Group type: Microsoft 365
3. Group name: DharmaInitiative
4. Membership type: Assigned
5. Owner: eigen administrator account
6. Member: mezelf toegevoegd

## Resultaat
- Microsoft 365 group "DharmaInitiative" aangemaakt in de Oceanic Airlines tenant

## Wat dit aantoont
- Praktische ervaring met Microsoft 365 groups, naast de eerder aangemaakte Security group (Flight-Operations)
- Begrip van het verschil tussen Security groups (access management) en Microsoft 365 groups (collaboration)
